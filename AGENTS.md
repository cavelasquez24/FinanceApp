# Instrucciones del repositorio

## Recomendación de modelo antes de implementar

Antes de iniciar cualquier requerimiento que implique cambios en el repositorio:

1. Indicar el modelo y el nivel de razonamiento recomendados.
2. Justificar la recomendación brevemente según complejidad, alcance y riesgo.
3. Esperar confirmación solo si el usuario pide evaluar o cambiar la configuración; de lo contrario, continuar con la implementación solicitada.

Usar el nivel más económico que mantenga una probabilidad alta de completar y verificar el cambio correctamente. Reservar niveles altos para arquitectura compleja, depuración difícil, migraciones riesgosas o cambios amplios.
